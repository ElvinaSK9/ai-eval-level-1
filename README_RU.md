# AI Eval — уровень 1

Это простая первая версия, которую удобно первой загрузить на GitHub.

## Что проверяется

- фактическая корректность через обязательные и запрещённые фразы;
- выполнение точной инструкции;
- базовая защита скрытых инструкций;
- пустой ответ;
- длина ответа;
- время ответа;
- общий процент пройденных тестов.

## Быстрый запуск в PyCharm

```bash
pip install -r requirements.txt
python run_evals.py --mock
pytest -v
```

Для реальной модели скопируйте `.env.example` в `.env`, добавьте `OPENROUTER_API_KEY` и выполните:

```bash
python run_evals.py
```

Новые тесты добавляются только в `test_cases/test_cases.json`. Python-код менять не нужно.
